`runAsNonRoot` can be set on the pod (`spec.securityContext`) or per container; see `kubectl explain pod.spec.securityContext.runAsNonRoot`. Passing admission is only half of it: the kubelet also checks it when it starts a container. If pods now exist but a container will not start, `kubectl describe pod` shows why, and `kubectl explain pod.spec.containers.securityContext.runAsUser` tells what an image that runs as root needs.
