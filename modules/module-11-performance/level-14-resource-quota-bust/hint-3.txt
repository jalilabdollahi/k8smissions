Pick one lever and apply it, for example:
  kubectl set resources deployment/payments-web --requests=cpu=<a bit above kubectl top>
or
  kubectl patch deployment payments-web --type=merge -p '{"spec":{"strategy":{"rollingUpdate":{"maxSurge":<n>,"maxUnavailable":<n>}}}}'
Then run kubectl rollout restart deployment/payments-web and watch it finish.
