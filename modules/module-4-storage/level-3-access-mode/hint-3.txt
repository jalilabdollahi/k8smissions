There is no ReadWriteMany provisioner here and access modes cannot be changed on an existing claim, so keep the claim. Change the spread rule so the scheduler may put several replicas on the volume's node:

  kubectl patch deployment web-servers -n k8smissions --type=json \
    -p '[{"op":"replace","path":"/spec/template/spec/topologySpreadConstraints/0/whenUnsatisfiable","value":"<value>"}]'

(valid values: DoNotSchedule or ScheduleAnyway)
