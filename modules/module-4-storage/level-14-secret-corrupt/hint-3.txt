Mount the whole Secret volume as a directory and let the app read the key from it, instead of mounting a single file:

  kubectl patch deployment api-consumer -n k8smissions --type=json \
    -p '[{"op":"replace","path":"/spec/template/spec/containers/0/volumeMounts/<index>","value":{"name":"token","mountPath":"<directory>","readOnly":true}}]'

The key is called token and the app reads /etc/api/token, so choose the directory so that this path exists. Updates do not arrive instantly: the kubelet refreshes volumes on a timer.
