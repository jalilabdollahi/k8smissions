Option A: create the missing class, copying what works from the existing one (the provisioner must be one that is actually running in this cluster):

  kubectl apply -f - <<'YAML'
  apiVersion: storage.k8s.io/v1
  kind: StorageClass
  metadata:
    name: <name-from-the-claim>
  provisioner: <provisioner-of-standard>
  volumeBindingMode: WaitForFirstConsumer
  YAML

Option B: storageClassName cannot be changed on an existing claim, so delete the claim and recreate it with a class that exists.
