Decide what each source should contribute. Restrict the source that must not provide `db.password` with `items`, for example by patching the Deployment's projected sources:

  kubectl edit deployment config-reader -n k8smissions
  # under volumes -> projected -> sources -> configMap add:  items: [{key: <key>, path: <file>}]

Reordering the sources is a fragile alternative, and deleting data from the Secret is not an option.
