Create a PersistentVolumeClaim (ReadWriteOnce, 1Gi is plenty), then swap the source of the volume mounted at /data. A merge patch would leave the emptyDir in place next to the claim, which the API rejects, so replace the whole entry:

  kubectl patch deployment data-app -n k8smissions --type=json \
    -p '[{"op":"replace","path":"/spec/template/spec/volumes/<index>","value":{"name":"uploads","persistentVolumeClaim":{"claimName":"<your-claim>"}}}]'

or use kubectl edit deployment data-app.
