volumeClaimTemplates cannot be added by patching an existing StatefulSet, so the StatefulSet has to be recreated, and the shared claim removed so nothing mounts it any more:

  kubectl delete statefulset postgres-cluster -n k8smissions
  kubectl delete pvc <shared-claim> -n k8smissions
  kubectl apply -f <statefulset with a volumeClaimTemplates entry named pgdata>

Save the YAML first: kubectl get statefulset postgres-cluster -n k8smissions -o yaml > sts.yaml
