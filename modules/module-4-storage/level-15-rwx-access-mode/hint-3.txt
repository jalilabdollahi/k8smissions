Replace the claim with a single-writer one (access modes cannot be edited on an existing claim), and change how the Deployment replaces pods so that the old one stops first:

  kubectl patch deployment ingest -n k8smissions --type=merge \
    -p '{"spec":{"strategy":{"type":"<strategy>","rollingUpdate":null}}}'
  kubectl delete pvc shared-pvc -n k8smissions
  # apply a claim named shared-pvc with accessModes: ["<single-writer mode>"]

Do not delete ingest-data: it holds v1's first batch. If deleting shared-pvc hangs, a Pending pod still references it.
