1. What the cluster's storage can provide: check the provisioner of the default class and what access modes it supports. This cluster has no shared (many-writer) filesystem, so a claim cannot ask for one.
2. How a pod holding a single-writer volume gets replaced: ingest-data is ReadWriteOncePod, so only one pod in the whole cluster may use it at a time, and the default rolling update starts the new pod before stopping the old one.
