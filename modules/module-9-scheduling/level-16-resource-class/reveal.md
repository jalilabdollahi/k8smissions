1. `describe pod` first says the DeviceClass `gpu.example.com` is not found. Read the driver from `kubectl get resourceslice -o yaml` (`gpu.lab.example.net`) and create the class:
   `kubectl apply -f -` with `kind: DeviceClass`, `metadata.name: gpu.example.com`, `spec.selectors: [{cel: {expression: 'device.driver == "gpu.lab.example.net"'}}]`.
2. The pod still cannot allocate: the template's own selector reads attribute domain `gpu.lab.example.com`, but the slices publish `gpu.lab.example.net`. Replace the template with the right domain (`kubectl get resourceclaimtemplate notebook-gpu -o json | sed ... | kubectl replace --force -f -`).
3. Delete the pod (`kubectl -n k8smissions delete pod -l app=lab-notebook`): the new pod gets a new claim, which the scheduler allocates from the slice of the node it picks.
