In `finally`, `$(tasks.status)` is an aggregate of the whole run, and a `when` expression only lets the Task start if its input matches one of the listed values; `kubectl explain pipeline.spec.finally.when` shows the fields, and the Tekton docs list the values the aggregate can take (Succeeded, Failed, Completed, None). Independently, `kubectl rollout undo` goes back to an older ReplicaSet, and a Deployment keeps those according to a field on its spec (`kubectl explain deployment.spec.revisionHistoryLimit`).
