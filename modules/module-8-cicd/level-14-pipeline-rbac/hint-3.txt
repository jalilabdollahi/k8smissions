`kubectl create role NAME --verb=create,get,list,watch --resource=pipelineruns.tekton.dev` then `kubectl create rolebinding NAME --role=NAME --serviceaccount=k8smissions:dispatcher`. Check with `kubectl auth can-i` for each verb, and for what must stay forbidden (secrets, pods, delete on pipelines). Then start a new run of `orchestrate` with `taskRunTemplate.serviceAccountName: dispatcher`.
