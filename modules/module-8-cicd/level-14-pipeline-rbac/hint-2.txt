Permissions come from a Role (what) and a RoleBinding (who) in the same namespace; the apiGroup for Tekton objects is `tekton.dev`. The Task does two different things, and each needs its own verbs: creating the child run is not the same as waiting for it. `kubectl wait` reads the object and then watches it, so think about `get`, `list` and `watch`. `kubectl create role --help` shows the shortcut.
