A docker config maps a registry host name to credentials, and the client looks them up by the exact host name and port it pushes to. The `auth` value is base64 of `user:password` and every byte counts, including a trailing newline that `echo` adds. `kubectl create secret docker-registry --help` builds a correct one for you. Tekton picks up `dockerconfigjson` Secrets listed on the run's ServiceAccount.
