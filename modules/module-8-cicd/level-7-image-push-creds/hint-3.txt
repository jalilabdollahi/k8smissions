Rebuild the Secret with the right server name and password: `kubectl create secret docker-registry registry-creds --docker-server=<host:port the step pushes to> --docker-username=ci-push --docker-password=<password from the old auth value> --dry-run=client -o yaml | kubectl apply -f -`. Then start a new run of `build-and-push` with `taskRunTemplate.serviceAccountName: builder`.
