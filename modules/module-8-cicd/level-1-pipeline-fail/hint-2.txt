Every step of a Task runs in its own container in the same pod, so `/tmp` is not shared between them. Only a few paths are: the Task's workspaces, `/workspace`, and the results directory. Task results are declared under `spec.results`, and `kubectl explain task.spec.results` shows the field; a step finds the file to write with `$(results.<name>.path)`. Note that the Task already declares a result called `version`.
