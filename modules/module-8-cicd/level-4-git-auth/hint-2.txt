Tekton hands a Secret to a step only if it is listed on the ServiceAccount the TaskRun runs as, and uses it for a Git server only if its `tekton.dev/git-0` annotation matches that server's URL: scheme, host and port, exactly. A run uses the `default` ServiceAccount unless `spec.taskRunTemplate.serviceAccountName` says otherwise (`kubectl explain pipelinerun.spec.taskRunTemplate`). There are two separate problems.
