Read the password from the sync side (`kubectl -n k8smissions get secret inventory-cache-credentials -o jsonpath='{.data.CACHE_PASSWORD}' | base64 -d`), then create the Secret the event names in `cache-tier`, with the key name the cache's volume expects: `kubectl -n cache-tier create secret generic <name> --from-literal=<key>=<password>`. After a crash loop, deleting the sync pod skips the restart back-off.
