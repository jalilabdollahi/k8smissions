`metadata.generation` only moves when the spec changes; `status.observedGeneration` is meant to be a copy of the generation the controller last handled, not a counter. Every status patch whose content differs from what is stored (a fresh timestamp, for instance) is a real write that bumps `resourceVersion`. Make the operator write status only when it has something new to say, but keep checking and repairing the children on every pass. The code lives in ConfigMap `inventory-operator-code`.
