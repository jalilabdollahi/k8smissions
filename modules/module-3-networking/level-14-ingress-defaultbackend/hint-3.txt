Fix the class with a patch: `kubectl -n k8smissions patch ingress docs --type=merge -p '{"spec":{"ingressClassName":"<an existing class>"}}'`. For the unknown hosts, a `defaultBackend` is honoured as the controller-wide fallback when it sits in an Ingress of its own with no rules: `kubectl -n k8smissions create ingress <name> --class=<class> --default-backend=<service>:<port>`.
