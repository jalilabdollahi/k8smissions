Follow the webhook's `clientConfig.service` to its Service and look at where it really sends traffic: `kubectl -n k8smissions get svc,endpoints,endpointslices config-guard -o wide` (a Service with no selector gets its endpoints from somewhere else). When the backend answers, the API server also has to trust it: `caBundle` must be the CA that signed the backend's certificate (`kubectl -n k8smissions get secret config-guard-tls` has more than the key pair). Finally, `inventory-sync` polls on an interval set by an environment variable.
