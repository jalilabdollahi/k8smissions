`kubectl -n k8smissions set image deploy/storefront <container>=<image without the mirror host> <init container>=<image>` works for init containers too, and the sidecar needs `kubectl -n k8smissions patch deploy storefront --type=json -p='[{"op":"replace","path":"/spec/template/spec/containers/<index>/imagePullPolicy","value":"<policy>"}]'`. Keep the same images (names and tags), only the host changes.
