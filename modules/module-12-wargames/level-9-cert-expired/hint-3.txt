Create the new Secret in place: `openssl ecparam -name prime256v1 -genkey -noout -out x.key`, `openssl req -new -key x.key -subj /CN=<name> -out x.csr`, `openssl x509 -req -in x.csr -CA ca.crt -CAkey ca.key -CAcreateserial -days 90 -extfile x.ext -out x.crt`, then `kubectl -n k8smissions create secret tls <name> --cert=x.crt --key=x.key --dry-run=client -o yaml | kubectl apply -f -`. Pods that mount a file with `subPath` need `kubectl -n k8smissions rollout restart deploy/<name>` to see it.
