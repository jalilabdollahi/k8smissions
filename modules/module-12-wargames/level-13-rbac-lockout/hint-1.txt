There are no pods to read logs from first, so ask the ReplicaSet: `kubectl -n k8smissions describe rs -l app=ledger-sync` (Events). Once pods exist, `kubectl -n k8smissions logs deploy/ledger-sync` prints a JSON status line every 5 seconds, with one error per API call. `kubectl -n k8smissions get sa,role,rolebinding` and the same in `platform-config` show what the rotation left behind.
