One strategic merge patch handles the pod template: `kubectl -n checkout patch deploy checkout -p '{"spec":{"template":{"spec":{"nodeSelector":{"pool":"<label value that exists>"},"securityContext":{"runAsNonRoot":true,"runAsUser":<non-zero uid>,"seccompProfile":{"type":"RuntimeDefault"}},"containers":[{"name":"app","securityContext":{"allowPrivilegeEscalation":false,"capabilities":{"drop":["ALL"]}},"startupProbe":{"httpGet":{"path":"/healthz","port":8080},"periodSeconds":5,"failureThreshold":<enough for 25s+>}},{"name":"log-shipper","securityContext":{"allowPrivilegeEscalation":false,"capabilities":{"drop":["ALL"]}},"resources":{"requests":{"cpu":"<small>"}}}]}}}}'`. Remove the taint with `kubectl taint nodes -l pool=general dedicated-` (or add a matching toleration). Then `kubectl -n checkout patch hpa checkout --type=merge -p '{"spec":{"maxReplicas":<n>,"metrics":[{"type":"Resource","resource":{"name":"cpu","target":{"type":"Utilization","averageUtilization":50}}}]}}'`.
