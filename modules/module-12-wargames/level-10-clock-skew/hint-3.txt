Remove the zone from auth: `kubectl -n k8smissions set env deploy/auth TZ-`. Give tokens a sensible life: `kubectl -n k8smissions set env deploy/auth TOKEN_TTL_SECONDS=<seconds>` and, if you want, `kubectl -n k8smissions set env deploy/api LEEWAY_SECONDS=<small number>`; keep the sum far below two hours. Make `api-verify` hold the same key as `auth-signing` (read it with `kubectl get secret auth-signing -o jsonpath='{.data.key}'`, patch the other with `kubectl patch secret api-verify --type=merge -p '{"data":{"key":"<value>"}}'`) and run `kubectl -n k8smissions rollout restart deploy/api`, because environment variables are read only at start.
