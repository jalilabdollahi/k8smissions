Argo CD's `selfHeal` option reverts any live change that differs from Git, within seconds. The value lives in the repository (`deploy/configmap.yaml` in `payments-api.git`), so Git is the only place a lasting change can be made. Turning automation off does not make the fix durable and the check requires self-heal to keep working. How long does the upstream take? `kubectl -n k8smissions exec probe -- curl -s -o /dev/null -w '%{time_total}\n' http://ledger-upstream`.
