A plain `helm upgrade` does not carry over earlier `--set` values: whatever is not passed falls back to the chart's `values.yaml`. Look at the chart's defaults (clone the `charts` repository from the Git server, or `helm show values`) and at `helm get values ledger-api --all`. Then decide where the production values should come from, and what happens to the image tag if you reuse an old revision's values as they are.
