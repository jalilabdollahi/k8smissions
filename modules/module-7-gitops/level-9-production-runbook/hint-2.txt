Argo CD runs a sync in phases: PreSync hooks, then the Sync phase (the Deployment is waited on until healthy), then PostSync hooks. Which phase is the migration in, and what does the new Deployment need before it can be healthy? A running operation is not replaced by a new commit: it has to be terminated (`status.operationState.phase: Terminating`) and a new sync requested. When the hook finally runs, read its pod's events: it depends on an object that is created in a later phase.
